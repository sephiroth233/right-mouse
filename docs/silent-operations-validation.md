# 静默操作本地验证（2026-09-23）

本次按用户要求移除所有正常操作的任务弹窗及历史入口。当前安装的 GitHub 应用未替换；本地构建只用于验证，暂不生成 DMG、不推送、不发布新版本。

## 行为

- 新建、复制文本、打开方式、剪切粘贴、复制到、移动到正常完成时不打开任务窗口。
- 菜单栏“文件任务”和演练“查看任务”入口移除。权限与诊断只显示需要手动核对的异常文件，不显示已完成操作列表。
- 重名选择保留；失败通过独立提示框显示。正常文件操作不进入诊断日志，旧的逐操作事件在读写诊断时过滤并重写。
- Commands、Receipts、Followups、Transfers 是临时通信与文件安全状态。请求过期且已安全终结后清理，空闲时每 5 秒检查，启动时补清。有效请求最长 120 秒，允许客户端时钟快 30 秒；执行未结束时不清理。清理后过期请求仍会被拒绝，防止重放。
- 不确定、损坏、未清理暂存及未完成的恢复现场继续保留，不自动重做或删除用户文件。无历史任务撤销入口。
