## 3. B 阶段：公共基础

- [ ] **T007 模型、配置与协议编码**。依赖：T006。实现版本化数据类型、Schema 等价验证、配置单写与原子更新、迁移备份、数量上限；添加配置损坏与未来版本测试。交付 Domain/Config/Codec。验收：AC-015、AC-025、AC-026，Schema 示例与运行时编码一致。
- [ ] **T008 菜单规则引擎**。依赖：T007。实现按场景可见/可用、分组排序、紧凑模式和不可变上下文；设置预览复用同一规则；配置异步缓存。交付 MenuPolicy 与扩展接入。验收：AC-001、AC-002、AC-015、AC-027；菜单构建不做重 I/O。
- [ ] **T009 访问和资源生命周期**。依赖：T004、T007。实现授权仓库、书签解析/更新、实际对象类型检查和作用域释放；覆盖每个错误返回。交付 AccessResolver。验收：AC-016、AC-017、AC-019、AC-026。
- [ ] **T010 请求接收与调度**。依赖：T005、T007、T009。实现 1 MiB/1024 限制、时效、去重、同 ID 不同内容拒绝、单消费者锁和回执；全局变更队列与只读任务分离。交付 Dispatcher/Inbox。验收：AC-023、AC-025、AC-026、AC-028。
- [ ] **T011 操作日志和恢复判定**。依赖：T007、T010。实现单写日志、阶段意图、原子更新、终态聚合、恢复只读核对和保留策略；注入日志写失败。交付 Journal/RecoveryCoordinator 的基础。验收：AC-018、AC-022、AC-023、AC-024；不得把“无回执”当作“无副作用”。

- [ ] **T012 模板与新建文件**。依赖：T008、T009、T010、T011。实现 6 种内置模板、单文件导入、可选变量、排他命名/提交、创建后定位。交付模板管理和创建器。验收：AC-003、AC-004、AC-005；并发创建不覆盖，JSON 有效、SH 不执行。
- [ ] **T013 文本复制与剪切会话**。依赖：T008、T010。实现 4 种复制格式、特殊字符、活动 PendingMove、剪贴板标记、时效和替换规则。交付 PasteboardAdapter。验收：AC-006、AC-007；重启后旧剪切失效，源字节/属性不变化。
- [ ] **T014 收藏与目标选择**。依赖：T009、T010。2026-09-23 按用户最新要求移除常用目录及最近目标入口；复制/移动直接选择目录并支持取消，旧收藏/最近记录保留读取兼容。交付目标选择流程和 DestinationResolver。验收：AC-011、AC-012、AC-017；删除收藏不删目录。
- [ ] **T015 文件操作引擎**。依赖：T011、T013、T014。实现规划、同卷 no-clobber、跨卷暂存/校验/提交/安全清理、逐项记录、失败项重试与 PendingMove 更新；先完成故障测试再接入 UI。交付复制/移动/粘贴。验收：AC-004、AC-008、AC-009、AC-010、AC-011、AC-019–AC-024，外部并发不确定时源保留。
- [ ] **T016 应用启动适配器**。依赖：T009、T010。验证并实现 Terminal、VS Code 的文件/目录语义；自定义 .app 仅开放测试过的能力；处理应用丢失和自动化权限。交付适配器及配置页。验收：AC-013、AC-014；空格、引号、换行等路径不转成额外命令。
- [ ] **T017 设置与菜单预览**。依赖：T008、T012、T014、T016。实现通用、菜单、模板、收藏、应用、文件操作默认询问（2026-09-23 调整：移除文件操作与任务记录侧栏入口）；紧凑模式与预览；深浅色和键盘操作。交付 SwiftUI 设置。验收：AC-005、AC-012、AC-015、AC-029。
- [ ] **T018 首次启动与诊断**。依赖：T009、T010、T017。实现启用扩展引导、目录选择、首个创建演练、状态诊断、脱敏导出。交付 onboarding/diagnostics。验收：AC-016、AC-017、AC-025、AC-028、AC-029；不得默认申请完整磁盘访问。
- [ ] **T019 任务窗口、冲突与恢复入口**。依赖：T011、T015、T017。实现逐项进度、等待用户、取消、冲突策略、部分成功、同卷有条件撤销和恢复核对。交付任务 UI 与恢复动作。验收：AC-010、AC-018、AC-021、AC-022、AC-024、AC-029；完成首次 G1 闭环演示。
