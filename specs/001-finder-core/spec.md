## 1. 范围与用户故事

目标是让本地文件管理中的创建、定位、整理与打开工具可以直接从 Finder 发起。V1 支持用户明确配置的普通本地目录；外接盘按文件系统实测列入支持矩阵。最低部署目标为 macOS 14，优先 arm64；本机 macOS 27 的成功不构成旧系统成功的证据。

| 故事 | 用户目标 | 对应需求 |
| --- | --- | --- |
| US-001 | 在正在浏览的目录创建有效文件并立即使用 | FR-001、FR-002、FR-003 |
| US-002 | 准确复制选中项的路径或名称 | FR-004 |
| US-003 | 将一批文件移动到指定位置，知道哪些成功 | FR-005、FR-006、FR-007、FR-012 |
| US-004 | 快速访问常用目录和启动工作工具 | FR-008、FR-009 |
| US-005 | 只保留常用菜单并解决授权问题 | FR-010、FR-011 |
| US-006 | 安装后长期稳定使用，关闭设置也能操作 | FR-013、FR-014 |

V1 不包含：图片转换、全局右键/手势拦截、任意脚本、远程服务、收费系统、永久删除、目录自动合并、系统文件写权限修复。云盘兼容调查属于 G0，备用入口完整产品化属于 V1.1。以下需求是针对本项目的选择，不是竞品行为事实。

## 2. 功能需求

| ID | 必须实现的行为 | 明确边界与失败结果 |
| --- | --- | --- |
| FR-001 | 在已配置且验证可用的目录显示菜单；区分空白、文件、目录、多选；捕获本次菜单上下文 | 无有效目录不得退回 home/current working directory；返回“请选择目标目录”或禁用操作 |
| FR-002 | 内置 TXT、MD、JSON、YAML、HTML、SH 模板；新建后选中/定位结果 | 默认名称 `未命名.ext`，重名从 `未命名 2.ext` 递增；不覆盖、不自动执行 SH |
| FR-003 | 导入真实单文件模板、编辑显示名/默认名、删除模板、排序 | 模板复制到应用存储；V1 拒绝符号链接和包目录模板，原样复制二进制内容；导入失败保留原配置 |
| FR-004 | 复制完整路径、名称、无最后一段扩展名的名称；多选按捕获顺序以换行连接 | 点文件如 `.env` 原样保留；可另选 POSIX shell 转义格式；路径内含换行时普通模式不保证可逆解析 |
| FR-005 | “剪切”建立待移动列表并写入自定义剪贴板标记 | 不移动/隐藏源；新剪切替换旧列表；其他应用改写剪贴板后标记失效 |
| FR-006 | “粘贴待移动文件”对有效列表执行移动，逐项清除成功项 | 失败/跳过项保留供重试；保留列表时更新标记，不能把成功项再次移动；相同源目标跳过并给理由 |
| FR-007 | 复制到/移动到可选常用目标、最近目标或目录选择器，支持多选与逐项结果 | 最近目标最多 10 项，持久书签失效时要求重新选择；重名默认询问，可跳过或保留两份，并可对本批后续冲突应用同一选择；不提供覆盖和目录合并；选择器取消无副作用 |
| FR-008 | 添加、改名、排序、删除收藏目录，并在 Finder 打开 | 重启后保留；目录改名尽力按书签重定位；失效显示修复入口，不跳到同名替代目录 |
| FR-009 | Terminal 在所选目录或文件父目录打开；VS Code 打开项目/文件；可添加自定义 .app | 缺少应用、拒绝自动化权限、适配能力不符须明确反馈；自定义应用默认只提供已验证的普通 URL 打开能力 |
| FR-010 | 菜单可开关、排序、分组；紧凑模式；预览区与真实菜单复用规则 | 下一次打开菜单采用新配置；不承诺控制系统自带菜单排序；损坏配置保留备份并恢复安全默认 |
| FR-011 | 引导启用扩展、配置目录与权限；诊断区区分每类状态 | 不默认索取辅助功能或完全磁盘访问；拒绝后保留可用功能；缺权限的任务等待或取消，不能静默报成功 |
| FR-012 | 文件任务展示计划数量、进度、逐项结果、取消；未完成操作可核对 | UI 超时不等于失败；恢复前验证状态；V1 仅同卷已完成移动满足条件时提供撤销，跨卷以恢复/核对为主 |
| FR-013 | 宿主未运行时能够从扩展启动并执行；同一请求重送只产生一个已知结果 | 进程崩溃后的未知状态进入核对，不承诺端到端 exactly-once；拒绝过期请求和不受支持协议 |
| FR-014 | 提供可安装应用、版本号、支持范围和卸载说明；正式分发构建完成签名与公证验证 | 开发签名构建必须标记为开发版；卸载不删用户原文件，历史待恢复任务先提示导出/核对 |

模板内容：TXT/MD/YAML 允许空白；JSON 为 `{}` 加换行；HTML 为最小 UTF-8 文档；SH 仅放置注释或 shebang，默认无执行权限。自定义变量初版只在明确选择的 UTF-8 文本模板启用，限定 `{{date}}` 和 `{{filename}}`，禁止解释表达式。date 使用首次接受命令时的本地日期 `yyyy-MM-dd` 并在任务中固定；filename 使用最终提交的完整文件名。重名重试须重新生成含 filename 的内容；二进制模板不替换变量。

自定义文件名必须是单个名称，拒绝空值、`.`、`..`、NUL 和路径分隔符；不将用户输入当相对路径。实际长度/字符支持由目标文件系统复核，超过限制给出可读错误而非静默截断。终端转义格式按 POSIX shell 单参数规则编码，不能把转义后文本直接视为可执行命令。

## 3. 非功能需求

| ID | 要求 | 验证口径 |
| --- | --- | --- |
| NFR-001 | 文件操作以保留源、拒绝覆盖为默认；不因取消、重复请求、崩溃而盲目删除 | 通过 AC-019–AC-024 故障和竞争测试；无法安全删除时结果必须为“源保留” |
| NFR-002 | 菜单构建本地 P95 < 50 ms；菜单路径无递归遍历、下载、哈希 | 同一真机发布优化构建，100 配置项×100 次打开，记录设备/系统和冷暖状态；系统弹出耗时另记 |
| NFR-003 | 命令仅执行白名单；外部唤醒 URL 不直接授权文件操作 | 严格协议、过期校验、大小限制、请求去重；伪造 URL/未知命令不产生文件变更 |
| NFR-004 | 核心离线可用；日志默认无正文、书签数据、完整用户路径 | 断网演练和日志检查；调试导出由用户主动触发并说明字段 |
| NFR-005 | 原生窗口使用液态玻璃风格，支持深浅色、键盘焦点与 VoiceOver 可读标签；启动窗口居中且大小适中 | 主窗口默认 960×680 pt，按当前屏幕可用区域居中，小屏保留边距；macOS 26+ 原生玻璃、旧系统磨砂降级，减少透明度/增强对比度时实色；设置、目标选择、任务与恢复入口手工验证 |
| NFR-006 | 按实测声明系统、架构、文件系统和提供方支持范围 | 最低目标 macOS 14 与实际发布系统各有证据；缺环境标记未测，不据此宣布支持 |

容量边界：一个请求最多 1024 个顶层选中项、JSON 最多 1 MiB；超限提示分批。目录子项不计入选择数，后台扫描需可取消。配置最多 100 个可见动作、100 个收藏和 100 个模板，达到上限时不静默截断。菜单指标在这些上限下测量。大文件流式处理，不按整个文件大小分配内存；具体缓冲大小由测量决定。

## 4. 场景语义与边界

### 4.1 目标目录决策

新建/粘贴在空白处使用浏览目录；在单个目录上触发时使用该目录；在单个普通文件上触发时使用父目录。多选同父目录时使用共同父目录，多选跨目录时明确要求选择目标。复制到/移动到始终使用显式选择目标。搜索/最近使用不推断虚拟位置为写入目录。

### 4.2 文件类型与身份

移动与复制默认保留符号链接本体；目录扫描不跟随符号链接。包目录按一个顶层项目展示，内部复制逐项验证。FIFO、socket、设备节点等特殊文件拒绝处理并显示原因。硬链接默认按内容复制，可不保留链接拓扑；不把该差异描述为字节丢失。只读源允许复制但移动可能以“源保留”结束。

隐藏文件和用户可读的扩展属性不应静默丢失。目标文件系统无法保留应用要求的资源叉/扩展属性或其他必要元数据时，复制可报告降级；跨卷移动须保留源并让用户核对，禁止自动按“完整成功”处理。

### 4.3 故障结果

权限拒绝、文件不存在、源被替换、目标重名、磁盘空间不足、卷被拔出、宿主崩溃均需区分。一个失败项目不把整批已成功项目改为失败；一批中既有成功又有失败/跳过时结果为 `partial`。重试仅针对明确失败项，生成新请求 ID 并关联原任务，不隐式重跑成功项。
