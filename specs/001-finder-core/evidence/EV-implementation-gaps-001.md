## 1. 下一批施工

| 优先项 | 当前行为与影响 | 实施边界 | 关联 |
| --- | --- | --- | --- |
| 批量冲突选择 | 每次冲突分别弹窗；回执未切换到等待用户，用户不能一次选择本批后续策略 | 增加一次/本批决策，持久等待状态，恢复后重新校验目标；保持禁止覆盖和合并 | T019、AC-010、AC-018 |
| 最近目标 | 非收藏目标仅在内存中保留，重启后需重新选择 | 持久化有上限的最近目标及安全书签；失效时修复或移除，路径文字不作为授权 | T014、FR-007 |
| 记录保留与诊断导出 | 任务与恢复记录没有按时间回收；复制诊断只包含即时摘要 | 终态记录按规格保留；未确认恢复记录不自动删；实现脱敏、容量受限的事件记录和主动导出 | T011、T018、AC-028 |
| VS Code 多目录语义 | 非 Terminal 应用统一接受整批 URL，跨目录文件缺少项目目录选择 | 分离 VS Code 的文件/目录适配，跨目录先选择；自定义应用只承诺验证过的能力 | T016、AC-013、AC-014 |

审查入口为 `AppModel.chooseDestination`、`MenuPolicy`、`HostController.resolveConflict`、`CommandLedger` 与 `ApplicationLauncher`。本表列出施工前状态；每项实现后添加提交及检查证据，并更新状态，避免将历史缺口重复安排。

## 2. 验收依赖

真实 Finder 到宿主的共享通信受当前 App Group 签名拒绝影响，需要有效身份和授权配置。原生 UI 工具在选择 RightMouse 时仍返回连接中断；几何计算和源码编译不证明真实窗口的视觉效果、键盘或 VoiceOver 体验。

真实跨卷、磁盘满、卷移除、最低 macOS 版本及正式分发验收继续保留未测状态。开发版本地存储降级只解决宿主启动，不构成 Finder 共享容器通过的证据。
