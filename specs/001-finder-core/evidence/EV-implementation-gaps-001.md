## 2. 验收依赖

真实 Finder 到宿主的共享通信受当前 App Group 签名拒绝影响，需要有效身份和授权配置。原生 UI 工具在选择 RightMouse 时仍返回连接中断；几何计算和源码编译不证明真实窗口的视觉效果、键盘或 VoiceOver 体验。

真实 APFS 镜像与宿主卷之间的复制、移动、元数据、取消和实际 ENOSPC 已通过 15 项检查，见[双卷证据](EV-real-volume-001.md)。外置卷移除、其他文件系统、最低 macOS 版本及正式分发继续保留未测状态。开发版本地存储降级只解决宿主启动，不构成 Finder 共享容器通过的证据。
