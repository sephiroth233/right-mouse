# 私有存储、引导演练与恢复清理集成

## 存储与迁移

完整配置、安全书签、模板内容、操作记录、诊断事件和原始备份存入宿主私有根目录。共享根只保留 Finder 必需的菜单显示快照、请求、回执和待移动摘要。菜单 DTO 不编码授权原件、模板正文、应用路径或操作历史；目录路径仍用于覆盖范围与菜单定位。宿主与扩展使用同一个菜单规则入口。

启动期间同时持有新旧账本锁，旧配置、模板和记录在同卷上逐文件执行禁止覆盖的原子迁移，原始字节不经过业务解码或重写。已迁移项目留在私有目录，未迁移项目仍在旧侧；中断后可继续。遇到同名冲突、跨卷、硬链接、符号链接或不可信对象时停止并保留现场，不发布成功快照。运行期正式宿主选择独立的 Application Support 根；开发降级使用开发目录中的 Host 子目录。旧布局兼容构造器仅供隔离夹具使用。

未来版本完整配置使宿主进入只读诊断：普通提交、撤销、重试和暂存清理均在执行入口阻止，启动时不清理过期记录。共享快照标记不可用；若共享侧本身是未来版本快照，旧宿主拒绝覆盖其原始字节。菜单发布失败会提示，宿主重启后重新尝试。

## 损坏记录保全

Commands、Transfers 和 Followups 中无法可信解析或版本不兼容的记录保留原件，并在私有 Backups 保存原始字节及小型元数据。副本按类别、记录 ID 和 SHA-256 去重。单个原始文件上限 8 MiB，总副本容量默认 64 MiB、最多 1024 份；超限或写入失败时报告失败，不删除原件。

备份只接受固定类别中的 UUID 文件名，并检查用户归属、文件类型、权限和硬链接数；通过目录描述符访问，拒绝链接替换。原始备份可能包含恢复所需敏感数据，因此不进入诊断导出。脱敏诊断和原始恢复副本使用不同的数据结构及导出入口。

## 引导与恢复交互

首次引导先选择目标目录，再显式创建 `RightMouse 演练.txt`。创建使用正式命令调度与模板引擎。模型在提交前安装请求 ID，等待时禁止重复提交；只接受匹配请求、支持版本、递增回执和唯一成功项目，才展示完成及定位入口。取消选择、失败和不匹配回执均不能变成演练成功。引导状态按当前会话保存，不假称跨启动教程进度持久化。

恢复页展示原始来源、目标、暂存路径和文件系统分配空间估算。取得有效来源及目标授权后，宿主只检查当前任务的暂存记录。旧记录缺少归属信息或授权不可用时保留现场并说明原因。只有 Core 返回可清理凭据时才出现确认入口；确认后通过宿主全局文件变更队列执行，队列内重新取得安全作用域并验证来源、父目录、暂存身份和日志摘要。清理不把原操作回执改写为成功。

清理期间禁用重复操作、刷新、核对确认和关闭核对页。成功后重新检查；失败显示错误并保留原任务状态。暂存删除协议与旧证据限制见[暂存恢复证据](EV-staging-recovery-001.md)。UI 已实现确认弹窗，但真实点击与视觉体验仍需系统 UI 验证。

## 验证与边界

本轮检查覆盖分层迁移与同名冲突、共享字段白名单、未来版本保护、备份去重及容量边界、真实 TXT 创建和回执、重启后重复请求、只读入口防护及清理模型。核心完整回归 298 项通过；宿主完整回归 337 项通过，其中新增首次演练 32 项、分层宿主 25 项、清理模型 18 项和真实清理集成 18 项。

真实清理检查使复制任务停在冲突提示，再提交暂存清理，验证队列等待期间暂存仍在；释放冲突后才执行清理。成功只删除目标暂存，原始 needsReview 回执逐字节不变。缺授权、来源变化、暂存 inode 替换和只读回调均拒绝删除；重复点击和旧回调不重复副作用。

原生宿主与嵌入扩展重新编译成功，ad-hoc 签名结构及 entitlements 校验通过。开发包为 `dist/RightMouse-0.1.0-development.zip`，SHA-256：`cc751f4971ed219a493fafc2b6628f6bfd1cacb3c194312d658dcd4959c65a95`。该包只代表本次开发构建，不代表 App Group 获得授权。

开发构建仍受当前 App Group 签名授权限制。当前环境的 Command Line Tools 编译和隔离检查不替代完整 Xcode XCTest、最低系统运行、真实 Finder、VoiceOver 或正式签名公证验收。液态玻璃样式及默认 960×680 pt 居中窗口继续沿用既有实现；本轮原生工具按路径选择应用返回 cgWindowNotFound，按已列出的 bundle ID 重试返回 native pipe closed，未取得新的真实截图证据。
